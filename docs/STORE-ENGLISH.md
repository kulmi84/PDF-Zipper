# English (United States)

## Short description
Interleave scanned front and back pages or merge PDFs in any order, directly in Windows 11 File Explorer. Local processing, compact dialogs and no overwriting.

## Description
PDF-Zipper combines PDF scans directly in Windows 11 File Explorer. Select your PDFs in the same folder, right-click and choose an action from the PDF-Zipper submenu.

Interleave PDFs
Scanned front and back pages separately? PDF-Zipper alternates front pages in their original order with back pages in reverse order. Select exactly two PDFs with equal page counts. Clear filenames and consecutive scan numbers help identify the front pages. When the choice is unclear, a compact dialog lets you select the front-page file.

Merge PDFs
Combine two or more PDFs into a single file. Use Move up and Move down in the compact order dialog to arrange your files. Different page counts are supported.

The result is saved in the same folder. Existing files are never overwritten, and your originals remain unchanged. All processing takes place locally on your PC, without an account, telemetry or app network connections.

Compact dialogs follow the light or dark Windows theme. Launching PDF-Zipper from the Start menu displays a short usage guide. No automatic startup or background service.

The interface uses German when your Windows display language is German, and English otherwise. Filename detection supports both German and English terms.

Requirements: Windows 11 on an x64 PC. All selected PDFs must be in the same folder. Password-protected or damaged PDFs are not supported. This tool is designed for scanned PDFs; digital signatures, bookmarks, PDF/A compliance and document-wide form features are not guaranteed to be preserved. Keep your originals.

## What's new
German and English interface, including Explorer actions, dialogs and error messages. The language follows your Windows display language.

## Features
- Interleave front pages with back pages in reverse order
- Merge two or more PDFs in a user-selected order
- Work directly from the Windows 11 Explorer context menu
- Process files locally without overwriting originals
- Compact dialogs with light and dark Windows themes
