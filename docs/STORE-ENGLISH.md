# English (United States)

## Description
Merge PDF files, combine documents and interleave scanned front and back pages directly in Windows 11 File Explorer with PDF-Zipper. Word documents and images can also be combined into a single PDF. Select at least two supported files in the same folder, right-click and choose an action from the PDF-Zipper submenu.

Merge as PDF
Combine PDF, Word (.doc/.docx), JPG/JPEG and PNG files in your chosen order. Word documents are exported using an installed desktop version of Microsoft Word. If Word is not installed, this action is disabled for selections containing Word documents; PDF and image merging work without Word. Each image is fitted proportionally onto an A4 page with 10 mm margins, including EXIF orientation. A compact progress window shows the current file during conversion.

Interleave PDFs
Scanned front and back pages separately? PDF-Zipper alternates front pages in their original order with back pages in reverse order. Select exactly two PDFs with equal page counts. Clear filenames and consecutive scan numbers help identify the front pages. When the choice is unclear, a compact dialog lets you select the front-page file.

Merge PDFs
Combine two or more PDFs into a single file. Use Move up and Move down to choose the order. Different page counts are supported.

The result is saved in the same folder. Existing files are never overwritten and originals remain unchanged. Processing is local. PDF-Zipper uses no accounts, telemetry or app network connections; Microsoft Word may use its own Office services. Word documents are opened read-only with document macros disabled.

Compact dialogs follow the light or dark Windows theme. The interface uses German when the Windows display language is German, and English otherwise. No automatic startup or background service.

Requirements: Windows 11 on an x64 PC. Word documents require installed and functional Microsoft Word. All selected files must be in the same folder. Password-protected or damaged documents, other file formats and multipage image formats are not supported. Word rendering depends on Word and installed fonts. Digital signatures, bookmarks, PDF/A compliance and document-wide form features are not guaranteed to be preserved. Keep your originals.
